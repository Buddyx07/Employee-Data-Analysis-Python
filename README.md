# 🧩 Employee Data Analysis using Python

## 📌 Overview
This project demonstrates data cleaning and analysis on employee records using Python and Pandas.

## 🛠 Tools Used
- Python
- Pandas
- CSV
- Jupyter Notebook / VS Code

## 🔄 Updating the Dataset
If you want to analyze a different employee dataset, simply replace the existing  
`employees.csv` file inside the `data/` folder with your new CSV file.

⚠️ Make sure the column names remain the same:
- EmployeeID
- Name
- Department
- Salary
- Status
- JoiningDate

No changes in the Python code are required.


## 🔍 Key Steps
- Loaded raw employee data
- Handled missing and incorrect values
- Removed duplicate records
- Performed department-level salary analysis
- Analyzed employee status distribution

## 📊 Key Insights
- Admin department has the highest average salary
- HR has the lowest employee count
- Most employees are Active

## 💡 Use Case
This project can be used for:
